# 02 ユーザーマニュアル（利用者向け）

この章は、フェリー手当管理を**使う人**向けの操作手順です。専門用語は `08_用語集・FAQ・既知の注意点.md` を参照してください。

## 1. はじめに：できること

- フェリーの利用実績を**複数件まとめて**登録できます。
- 航路を選ぶと、**フェリー会社と手当額が自動で入ります**。
- 登録済みの実績を**月ごとに確認・修正・削除**できます。
- **社員ごとの月間手当額と件数**を確認でき、**CSV**に出力できます。
- フェリー会社・航路・手当額・乗車名（車番ごとの通常の乗車社員）を**管理**できます。

WordPress の管理画面を開き、左メニューの「**フェリー手当**」から操作します。

## 2. 使い始める前の準備

### 2-1. 先に登録が必要なもの

| 必要なもの | 登録する場所 | 備考 |
|---|---|---|
| 車番 | 「車両管理」ツール | 車番は車両管理に登録されているものだけ使える |
| 乗車名（社員） | 「社員情報」ツール | 社員情報に登録済み（在籍）の社員だけ選べる |
| フェリー会社 | フェリー手当 → マスタ管理 → フェリー会社マスタ | 航路に会社を紐づける場合 |
| 航路・手当額 | フェリー手当 → マスタ管理 → 航路マスタ | 初期状態で24航路が登録済み |
| 乗車名マスタ | フェリー手当 → マスタ管理 → 乗車名マスタ | 管理者のみ。車番から乗車名を自動表示するため |

候補に出てこない車番・社員は登録できません。入力画面に「**＋車両管理で登録**」「**＋社員情報で登録**」というリンクが出る場合があり、新しいタブで該当の登録画面を開けます。

### 2-2. 初めての設定の順番

1. 「マスタ管理」→「フェリー会社マスタ」で会社を登録
2. 「航路マスタ」で航路・会社・手当額を確認／登録（初期24航路は登録済み）
3. （管理者）「乗車名マスタ」で車番と通常の乗車社員を登録
4. 「フェリー手当入力」で実績を登録

## 3. 利用実績を登録する（フェリー手当入力）

「フェリー手当」→「**フェリー手当入力**」を開きます。1行が1回の乗船です。**往復したときは2行**入力します。

### 手順

1. **乗車月日**を入力します（日付ピッカー、または `2026/10/05` のように入力／コピペ）。
2. **航路名検索**欄に、航路の**番号**または**航路名**を入力し、出てくる候補から選びます（例: `1 神戸 ⇔ 新門司`）。
   - 選ぶと「フェリー会社」「航路」「フェリー手当」が**自動で入ります**（この3欄は手入力できません）。
3. **車番**を入力し、候補から選びます。
   - 車番を選ぶと、**乗車名が自動表示**されます（乗車名マスタに登録がある場合）。
4. 乗車名が違うとき（代役など）は「**手動選択**」を押して社員を選び、「**反映**」を押します（→ 3-1）。
5. 行が足りなければ「**＋ 行を追加**」を押します（最後の行に入力すると自動で空行も増えます。最初は3行表示）。
6. 画面下の「**合計**」でその回の手当合計を確認します。
7. 「**登録**」を押します。

### 3-1. 乗車名を手動で選ぶ（イレギュラー時）

- 「手動選択」→ 社員を選択 →「反映」。ボタンの表示が「**選択中**」に変わり、乗車名欄が色付き（手動選択の状態）になります。
- この選択は**乗車名マスタより優先**されます。車番を変更しても、手動選択した乗車名は変わりません。
- 自動の乗車名に戻すには、もう一度「選択中」ボタンを押し、「**自動入力に戻す**」を押します。
- 社員を選ばずに「反映」を押すと「社員を選択してください。」と表示されます。「キャンセル」／Escキー／背景クリックで閉じます。

### 3-2. 登録時のルール

- **空の行は登録されません**（日付・航路・車番・乗車名のすべてが空の行）。
- 入力した行に**誤りが1つでもあると、その回は1件も登録されません**。表示された案内に従って直し、もう一度「登録」します。
- **同じ社員・同じ日付・同じ航路**の実績がすでにあると警告が出ますが、**登録自体は行われます**（重複登録）。警告が出たら「実績一覧・編集」で重複していないか確認し、不要なら削除してください。
- 登録に成功すると「**○件を登録しました。**」と表示され、入力欄は空（3行）に戻ります。

### 3-3. エラーメッセージと対処

| 表示 | 意味 | 対処 |
|---|---|---|
| 入力された行がありません。 | 何も入力されていない | 日付・航路・車番・乗車名を入力 |
| ○行目：乗車月日を入力してください。 | 日付が空 | 日付を入力 |
| ○行目：乗車月日は YYYY/MM/DD 形式で入力してください。 | 日付の形式が不正（存在しない日付含む） | `2026/10/05` の形式で入力 |
| ○行目：航路が正しくありません。 | 候補にない航路／無効な航路 | 候補から選び直す |
| ○行目：車番を入力してください。 | 車番が空 | 車番を入力 |
| ○行目：車番「xxx」は車両管理ツールに登録されていません。 | 車両管理にない車番 | 車両管理で先に登録 |
| ○行目：乗車名を入力してください。 | 乗車名が空 | 車番を選ぶか「手動選択」 |
| ○行目：車番に乗車名が紐づいていません。「手動選択」を使用してください。 | 乗車名マスタに未登録の車番 | 「手動選択」で社員を選ぶ（または管理者に乗車名マスタ登録を依頼） |
| 【重複警告】…同じ実績が既にあります（重複登録しました）。 | 同一社員・日付・航路が既にある | 実績一覧で確認し、不要なら削除 |
| 権限がありません。 | 閲覧のみで編集権限がない | 管理者に権限を確認 |
| 通信エラーが発生しました。 | 通信失敗 | 再度お試し |

> 画面に表示される「○行目」の番号は入力シート上の行位置です。空行を挟むと、サーバー側の「○行目」（空行を除いた順）とずれることがあります（→ `08` の注意点）。

## 4. 登録内容を確認・修正・削除する（実績一覧・編集）

「フェリー手当」→「**実績一覧・編集**」を開きます。

### 4-1. 一覧を表示する

1. **対象年月**（年・月）を選びます。選ぶと自動で表示されます（「表示」ボタンでも表示）。開いた直後は「『表示』を押してください。」と出ています。
2. 一覧の列: 乗車月日／航路番号／航路／フェリー会社／運輸支局／車番／乗車名／手当／操作。
3. 一覧下の「**合計**」に、表示中の手当の合計が出ます。
4. **列見出しをクリック**すると並べ替えできます（もう一度で昇順⇔降順、▲▼表示）。初期は乗車月日の昇順です。車番は数字の大きさ順（39 の次に 3000）に並びます。

### 4-2. 絞り込む

| 条件 | 内容 |
|---|---|
| 乗車月日（開始〜終了） | 期間を指定。**指定した場合は「対象年月」より優先**されます |
| 乗車名 | その期間に実績がある乗車名だけが候補に出ます |
| 車番 | その期間に実績がある車番だけが候補に出ます |
| 条件クリア | すべての絞り込みを解除して再表示 |

- 開始日が終了日より後だと「乗車月日の開始日が終了日より後になっています。」と表示されます。
- 期間を変えて、選択中の乗車名・車番が候補から消えた場合は、自動で「すべて」に戻って再取得されます。

### 4-3. 実績を修正する

1. 対象行の「**編集**」を押す（画面上部に編集フォームが開く）。
2. 乗車月日・航路名検索・車番・乗車名を直す（フェリー会社・航路・手当は自動表示）。
3. 「**更新**」を押す。やめるときは「キャンセル」。

**更新するとき重要な点**: 更新時は、航路の**現在のマスタ**から航路名・フェリー会社・**手当額**が取り直されます。つまり、航路の手当額を変更したあとで古い実績を編集（更新）すると、**新しい手当額に変わります**。金額を変えたくない実績は、必要がなければ編集しないでください。

- 同じ社員・日付・航路の実績が他にもあると「同じ社員・日付・航路の実績が他にもあります（更新は行いました）。」と警告が出ます（更新は行われます）。
- 無効化・削除された航路の実績は、編集時に航路が入力候補にないため、航路を選び直さないと更新できません。

### 4-4. 実績を削除する

対象行の「**削除**」→ 確認画面で「OK」。**削除は元に戻せません**。対象行をよく確認してください。

## 5. 月ごとの手当を確認する（月次サマリ）

「フェリー手当」→「**月次サマリ**」を開きます。給与ソフトへ入力する数字を確認する画面です。

1. 対象年月を選び「**表示**」を押す。
2. 社員ごとの「**フェリー手当（月）**」と「**件数**」、最下行に全員の**合計**が出ます。
3. **実績がある社員だけ**が表示されます。社員は社員コード順です。
4. 金額に疑問があれば、「実績一覧・編集」で元の実績を確認します。

### CSV出力

1. 対象年月を選ぶ。
2. 「**CSV出力**」を押す。
3. ファイル名 `ferry-allowance-YYYY-MM.csv`（例: `ferry-allowance-2026-10.csv`）がダウンロードされます。

- 列: 氏名／フェリー手当（月）／件数（合計行はCSVに含まれません）
- 文字コードは UTF-8（BOM付き）で、Excel で文字化けしにくい形式です。
- 氏名が `=`、`+`、`-`、`@` で始まる場合は、数式として誤認されないよう先頭に `'` が付きます。
- 「表示」を押していなくても、選択中の年月で最新の集計を取得して出力します。
- 実績がない月は、ヘッダー行だけのCSVになります。

## 6. マスタを管理する（マスタ管理）

「フェリー手当」→「**マスタ管理**」。上部のタブで切り替えます（航路マスタ／フェリー会社マスタ／乗車名マスタ）。

### 6-1. フェリー会社マスタ

- **登録**: 会社名（必須・100文字まで）と表示順（任意・数字）を入力して「登録」。「有効」チェックのまま登録します。
- **編集**: 一覧の「編集」→ 左フォームで直して「更新」。やめるときは「キャンセル」。
- **無効化／有効化**: 使わなくなった会社は**削除より無効化がおすすめ**です。無効にすると新しい航路の選択肢に出なくなります。
- **削除**: 物理削除です。「（登録済みの航路・実績には影響しません）」と確認が出ます。
- **検索**: 会社名で検索。「無効も表示」で無効の会社も一覧に出せます。
- 同じ会社名は登録できません（「この会社名は既に登録されています。」）。

### 6-2. 航路マスタ

| 項目 | 内容 |
|---|---|
| 航路番号（必須） | 1以上の整数。ほかの航路と重ならない（「この航路番号は既に登録されています。」） |
| 航路名（必須） | 100文字まで（例: 神戸 ⇔ 新門司） |
| フェリー会社 | 未設定でも登録できる。有効な会社から選ぶ |
| フェリー手当（必須） | 0円以上の整数（0円可） |
| 表示順 | 空欄なら航路番号と同じ |
| 有効 | チェックを外すと入力候補に出なくなる |

- **手当額を変更しても、すでに登録済みの実績の金額は変わりません**（新しく登録・更新した実績から新額）。
- 使わない航路は削除より**無効化**がおすすめ。無効な航路は新しい入力候補に出ませんが、過去の実績の航路名・金額は変わりません。
- 一覧は番号・航路名で検索できます。

### 6-3. 乗車名マスタ（管理者のみ）

車番と、通常その車に乗る社員の対応表です。入力画面ではこれを使って**乗車名が自動表示**されます。変更しても**過去の実績には影響しません**。

- 車番は車両管理に登録済みのものから、乗車名は在籍中の社員から選びます。
- 1つの車番につき1件だけ登録できます（「この車番は既に乗車名マスタへ登録されています。」）。
- 編集時は車番を変更できません（社員と有効/無効のみ変更）。
- 一覧は車番・社員コードで検索できます（氏名では検索できません）。
- 無効にした／車両管理から削除された車番／在籍でなくなった社員の紐づけは、入力画面の自動表示には使われません。

## 7. 運用上の注意（要点）

- 航路の手当額を変更しても、登録済みの実績の金額は変わりません。変更後の額は、新しく登録または更新した実績に使われます。
- 入力候補にない車番・乗車名は登録できません。先に「車両管理」「社員情報」で登録してください。
- 画面は見られるのに登録・変更できない場合は、権限がありません。管理者に確認してください。
- 削除（実績・マスタ）は元に戻せません。
- 社員の氏名は、一覧・サマリでは**社員情報の最新の氏名**が表示されます（改姓などは過去の実績の表示にも反映されます）。

## 8. よくある困りごと（Q&A）

**Q. 車番を入力しても乗車名が出ない。**
A. 乗車名マスタにその車番の登録がないか、無効になっています。「手動選択」で社員を選ぶか、管理者に乗車名マスタへの登録を依頼してください。

**Q. 車番が候補に出ない／赤く表示される。**
A. 車両管理に登録されていません。「＋車両管理で登録」から登録してください。

**Q. 航路を入力すると赤くなる。**
A. 候補にない航路番号／航路名か、無効な航路です。候補から選んでください。

**Q. 往復はどう入力する？**
A. 行きと帰りを別々の行に入力します（2行）。

**Q. 間違えて同じ実績を2回登録した。**
A. 「実績一覧・編集」で重複している行を「削除」してください。

**Q. 先月の手当額が勝手に変わった。**
A. 登録済み実績の金額は、航路マスタを変えても変わりません。ただし、その実績を「更新」すると現在の手当額に変わります。

**Q. サマリに載らない社員がいる。**
A. その月に実績がない社員は表示されません。
