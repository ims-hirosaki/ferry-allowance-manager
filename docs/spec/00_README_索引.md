# フェリー手当管理プラグイン 仕様書セット（索引）

> この文書セットは、ソースコード（バージョン 1.3.0）から逆生成した仕様書です。
> NotebookLM / Gem のソースとして読み込ませ、**エンジニア視点**と**利用者（業務ユーザー）視点**の両方の質問に答えられるように構成しています。

## 1. システムを一言で言うと

「フェリー手当管理」は、運送会社（有限会社たんぽぽ運送）の社内 WordPress 管理画面で動く**プラグイン**です。
ドライバーがフェリーに乗った実績（いつ・どの航路・どの車両・誰が乗ったか）を登録すると、航路ごとに決まっている**フェリー手当（円）**が自動で入力され、**月ごと・社員ごとの手当合計**を集計して給与ソフトへ入力するための数字（画面表示・CSV）を出せます。

- プラグイン名: フェリー手当管理（ディレクトリ名 `ferry-allowance-manager`）
- バージョン: 1.3.0
- 作成者表記: 有限会社たんぽぽ運送
- 動作基盤: WordPress 管理画面 + PHP + MySQL + jQuery（ビルド工程なし）
- 依存プラグイン: `employee-manager`（社員情報管理）、`vehicle-manager`（車両管理）

## 4. 表記ルール

- 「**〜と画面に表示される**」のような引用は、ソース内の実際の文言です（日本語メッセージはそのまま記載）。
- `class-xxx.php` などの表記は、リポジトリ内の実ファイルを指します（`06` に一覧あり）。
- 「**【ソース】**」の行は、その記述の根拠となるファイルです。
- 「**【推測・要確認】**」は、ソースだけでは確定できない事項です（他プラグイン側の仕様など）。

## 5. 用語のクイックリファレンス

| 用語 | 意味 |
|---|---|
| 航路 | フェリーの区間（例: 神戸 ⇔ 新門司）。番号（航路番号）で管理 |
| 航路マスタ | 航路番号・航路名・フェリー会社・手当額の一覧 |
| フェリー手当 | 1回の乗船ごとに社員へ支払う手当（円）。航路ごとに金額が決まっている |
| 実績 | 1回の乗船の記録（乗車月日・航路・車番・乗車名）。1行=1乗船 |
| 車番 | vehicle-manager の「一連指定番号」（serial_number） |
| 乗車名 | 乗船した社員。社員コードで保存される |
| 乗車名マスタ | 「この車番には通常この社員が乗る」という対応表 |
| スナップショット | 登録時点の航路名・手当額などを実績にコピーして保存すること。後でマスタを変えても過去実績は変わらない |
| 運輸支局 | 車番に紐づく運輸支局名（vehicle-manager から取得し、実績一覧で表示） |

詳細は `08_用語集・FAQ・既知の注意点.md` を参照してください。

## 6. Gem / NotebookLM で使うときのヒント

### 推奨するカスタム指示（Gem の「指示」欄に貼る例）

```
あなたは「フェリー手当管理」WordPressプラグインのサポート担当です。
添付の仕様書（00〜08）だけを根拠に、日本語で回答してください。
- 質問者が業務ユーザーと思われる場合: 専門用語を避け、画面の名前・ボタン名・手順（番号付き）で答える。
- 質問者がエンジニアと思われる場合: ファイル名・クラス名・関数名・テーブル/カラム名・AJAXアクション名・権限名を示して答える。
- 立場が不明な場合は、先に利用者向けの回答を示し、続けて「技術的な補足」を付ける。
- 仕様書に書かれていないことは推測で断定せず、「仕様書には記載がありません」と伝える。
- 「【推測・要確認】」と書かれている事項は、確定情報ではないと明示する。
- 金額・件数・権限・エラーメッセージは、仕様書の記載どおりに正確に引用する。
```

### ファイル分割の意図

- 1ファイル1テーマにし、見出し（`##`/`###`）を細かく付けています。AIが該当箇所を引きやすくするためです。
- 重要な事実（金額・権限・メッセージ）は**表**にしています。
- 同じ重要ルール（例: スナップショット、重複は警告のみ）は、利用者向け（02）・業務ルール（04）・技術（06）で**意味を揃えて重複記載**しています。どのファイルから参照されても答えがぶれないようにするためです。
